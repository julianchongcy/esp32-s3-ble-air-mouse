# ESP32-S3 BLE Air Mouse

A motion-controlled BLE HID air mouse prototype built with ESP32-S3 and MPU6050.

## Features

- Motion-based cursor control
- BLE HID mouse communication
- Left click and right click
- Scroll mode switching
- Cursor smoothing
- Scroll inertia
- Deadzone filtering
- Sensitivity tuning

## Hardware

- ESP32-S3
- MPU6050
- Push buttons
- Breadboard and jumper wires

## Technologies Used

- Arduino C++
- BLE HID
- I2C communication
- MPU6050 motion tracking
- Embedded systems debugging

## Project Status

Functional prototype completed.
